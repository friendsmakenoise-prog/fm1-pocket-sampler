# v0.2.3 - Orange B-Boy build

- Orange FM-1-inspired hardware skin.
- Master trim stage before chop generation.
- Auto-centred hardware zoom and edit focus.
- Three independent sampler tracks: SAMPLE A / B / C.
- Final three physical keys select A / B / C.
- Each track retains its own source, trim, chop mode, chop settings and MONO/POLY state.
- Three sampler engines now mix together in the desktop audio callback.
- Simple per-track MONO/POLY voice behaviour.
- Linked slice-length edit retained.
- Manual punch chopping constrained to the master trim region.
- PLAY/STOP previews only the master-trimmed region.
- Updated docs and tests.
- Raylib 5.5 rounded-line API hotfix incorporated.
