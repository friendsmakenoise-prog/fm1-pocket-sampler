# v0.2.6 — Master Trim Audition + Keybed Map Fix

- MASTER TRIM no longer jumps back to CHOP when a playable key is pressed.
- First five white keys become dedicated trim-audition tools:
  1. PRE — one second before MASTER START
  2. GATE — MASTER START to END while held
  3. 1SHOT — MASTER START to END once
  4. LOOP — MASTER START to END repeatedly while held
  5. TAIL — one second after MASTER END
- PLAY/STOP remains a convenient one-shot master preview / stop control.
- K3 and K4 are deliberately left free in MASTER TRIM.
- Corrected the desktop QWERTY mapping so the displayed F-based chromatic keyboard and computer keys line up:
  `Z S X D C F V B H N J M | Q 2 W 3 E 4 R T 6 Y 7 U`.
- Retains v0.2.4 chop-marker visibility and auto-centred chop zoom.
